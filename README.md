# Swarohi wedding website

A responsive wedding landing page for Swathi & Rohithashva — 9 May 2027.

## Files
- `index.html` — page structure, countdown and RSVP behavior
- `style.css` — responsive styling
- `wedding.json` — editable event details and RSVP email

## Before publishing
1. Open `wedding.json`.
2. Add your venue, full address, ceremony time and RSVP email.
3. Upload all three files to the root of your Git repository.
4. Enable GitHub Pages (Settings → Pages) or connect the repository to your hosting provider.

The RSVP form opens the visitor's email app using the address in `wedding.json`. It does not store submissions online. For automatic RSVP collection, connect a form backend (such as Formspree) and update the form handler.
